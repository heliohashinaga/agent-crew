# agentic-relay

> A swarm of AI agents collaborating across the software development lifecycle.

[![CI](https://github.com/heliohashinaga/agentic-relay/actions/workflows/ci.yml/badge.svg)](https://github.com/heliohashinaga/agentic-relay/actions/workflows/ci.yml)

This repository focuses on **agent-to-agent interaction in the software
development cycle**: specialized AI agents that hand work between one another —
planning, building, testing, reviewing and securing a change — instead of a
single model doing a single pass.

> **Status: fresh start.** The previous `src/ai_factory` implementation and the
> `specs/` design documents were removed. The project is being rebuilt from
> scratch around the swarm/interaction vision above.
